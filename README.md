##  Getting Started

Follow these steps to run the programs on your computer.

### Prerequisites

- Install [Python 3](https://www.python.org/downloads/).
- Install a code editor such as [Visual Studio Code](https://code.visualstudio.com/).
- Basic familiarity with running Python scripts.

### Clone the Repository

Open a terminal and execute:

```bash
git clone https://github.com/YOUR-USERNAME/python-learning.git
```

Navigate to the project directory:

```bash
cd python-learning
```

Open the folder in VS Code:

```bash
code .
```

### Run a Python Program

Navigate to the desired chapter folder and run a Python file:

```bash
python filename.py
```

On some Windows systems, you may need to use:

```bash
py filename.py
```

Replace `filename.py` with the name of the Python program you want to execute.
